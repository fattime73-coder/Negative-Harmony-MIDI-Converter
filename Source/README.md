# Negative Harmony MIDI Converter — macOS MVP 1.0

Swift / SwiftUI製のネイティブMacアプリです。MIDIノートをpitch-class inversionで変換し、元MIDIと聴き比べて標準MIDIとして書き出せます。ネット接続・外部ライブラリ・アカウントは不要です。元ファイルは上書きしません。

## 起動

同梱の **Negative Harmony MIDI Converter.app** を開きます。macOS 13 Ventura以降。配布ビルドはApple Silicon用です。Intel Macでは下の方法でソースからビルドできます。

この配布物はローカルのad-hoc署名であり、Appleによる公証は行っていません。他のMacへの転送でmacOSの確認が出る場合があります。管理対象のMacでは管理者の方針に従ってください。

## 使い方

1. 「デモ」で動作を試すか、「MIDIを開く」または大きな読み込み枠へのドラッグ＆ドロップで`.mid` / `.midi`を読み込みます。1ファイルずつ扱います。
2. Key（主音）とMajor / Minorを選びます。MIDIの調を自動検出する機能ではありません。
3. 下部の「トラックの役割」でメロディ／コード／変換しないを指定します。重なりがあるトラックはコードとして仮判定します。誤判定は手動で直してください。
4. メロディのみ／コードのみ／両方を選びます。設定変更後は自動変換されます。
5. 必要に応じて転回形、オクターブ、Voice Leading、Harmony Blendを調整します。
6. 「Original」「Negative」でそれぞれ再生。「比較再生」はOriginalを最後まで再生してからNegativeを再生します。「■」で停止します。Negative側の再生・表示・書き出しには現在のBlend設定が適用されます。完全な反転だけを聴くにはBlendを100%にしてください。
7. 「書き出し」で保存先を選びます。「Logicへドラッグ」をFinderまたはDAWへドラッグすることでも、現在の変換結果のMIDIファイルを渡せます。

キーボード：⌘Oで読み込み、⌘Sで書き出し。内蔵GM音源を使います。元のDAWのプラグイン音色を再現するものではありません。

## Logic Proへ戻す

Logic側にソフトウェア音源トラックを用意し、アプリ下部の「Logicへドラッグ」からトラック領域へドラッグしてください。これは通常の`.mid`ファイルの受け渡しです。受け取り方や複数トラックの展開方法はLogicの状態・バージョンに依存します。ドラッグが受け取られない場合は「書き出し」で保存し、そのMIDIをFinderからドラッグ、またはLogicのMIDI読み込み操作で開いてください。MIDIに含まれるテンポの採用はLogic側で判断してください。

メロディ用MIDIとコード用MIDIが別々の場合は、DAWで別トラックとして1つのSMFにまとめてから読み込みます。1つのトラックの中に混在した旋律と伴奏は自動分離しません。

## 反転の定義

各音のpitch classを `p`、主音を `t` とすると、標準の式は以下です。

```text
p' = (2 × t + 7 − p) mod 12
```

Cを主音とする場合：`C↔G, D♭↔G♭, D↔F, E♭↔E, A♭↔B, A↔B♭`。
したがってC–G–DはG–C–Fになります。コード名の文字列置換は行いません。変換されたMIDI構成音を再解析してコード名を表示します。

- **Classic Negative Harmony / Tonic–Dominant axis**：このMVPでは同じ主音↔属音の標準反転を、説明の異なる2つの選択肢として用意しています。別の結果になる算法ではありません。
- **Major / Minor**：調の指定として保持しますが、同じ主音では同じ反転式になります。スケールへの丸め・短調の第6/7音の自動変更はしません。
- **Custom axis**：「Cの変換先」を`s`として `p' = (s − p) mod 12`。pitch-classの対称軸は`s/2`とその6半音上です。半音間の軸にも対応します。
- C→Cm、Am→E♭、F→Gm。G7の反転構成音はC・D・F・A♭で、Fm6またはDm7♭5と解釈できます。Fm7ではありません。実際の表示はベース音に応じた分数コードになります。

## 最適化とBlend

- **オクターブ自動最適化**：反転後のpitch classを保ったまま、元の音域に近いMIDI音高を選びます。OFFでは中央C付近の固定反転を基準とします。MIDI範囲0〜127を守ります。
- **Voice Leading**：同じトラック・チャンネル内の前の同時発音グループとの音高距離を、元音域への近さと併せて評価します。局所的な貪欲法です。楽曲全体の最適解や声部の厳密な追跡を保証しません。
- **転回形維持**：完全一致で認識できる同時発音コードについて、元コードのベースが構成音列の何番目かを変換先に引き継ぎます。構成音列は根音・第3音（susでは代替音）・第5音・第7音・テンションの順で扱います。解釈が複数ある和音では、選ばれたコード名に対する転回形です。認識できない和音・ずれて発音するアルペジオには適用しません。元の実音のベースをそのまま残す機能ではありません。
- **Harmony Blend**：0%でOriginal、100%でNegative。中間値はトラック・チャンネルごとに同時発音グループを順番に数え、累積比率に従って原音／反転音を選びます。たとえば50%は原音→反転音の交互です。音量クロスフェードやピッチの連続補間、両方の音の重ね合わせではありません。短いフレーズでは割合に丸めが生じます。
- 最適化やBlendでノートON/OFFの対応が変わる衝突が起きた場合は変換を停止します。Blendを0%または100%にする、またはDAWでトラックを分離してください。

## MIDI保持範囲

標準MIDI SMF Format 0 / 1、PPQタイミングに対応。ノート開始tick、終了tick、Note Onベロシティ、Note Offベロシティ、MIDIチャンネル、トラック分けを保持します。ノート数は増減しません。テンポ、拍子、CC、Program Change、Pitch Bend、Channel Pressure、歌詞・マーカー等のメタイベント、SysExは元イベントのまま保持します。Running Statusは読み込み時に展開するのでバイナリとしては元と一致しない場合があります。

Poly Pressureは該当ノートが一意なら変換先ピッチへ追従します。曖昧な場合は元値を残して注意を表示します。ドラムとして一般的なMIDIチャンネル10は変換しません。他のチャンネルの打楽器は役割を「変換しない」にしてください。

同じ音高のノートが重なる入力はFIFOでNote Offを対応付けます。SMF自体にノート識別子がないため、DAW独自の対応は再現できません。同一ピッチの重複を検出した場合は注意を表示します。Note Offが欠けたファイルや不正なデータは、長さを勝手に補わずエラーにします。

## コード解析・比較表示

major / minor / 6 / 7 / maj7 / m7 / m(maj7) / dim / dim7 / m7♭5 / aug / aug7 / sus2 / sus4 / 7sus4 / 9sus4 / add9 / madd9 / add11 / madd11 / add13 / 9 / maj9 / m9 / 11 / maj11 / m11 / 13 / maj13 / m13 / 13(no11)系 / 7♭9 / 7♯9 / 7♯11 / 7♭13の構成音テンプレートを実装しています。

完全一致した候補のうちベースと根音が一致する解釈を優先します。C6とAm7などの異名・多義性はあります。登録外、根音省略、その他の省略ボイシングは構成音名を表示します。名前を特定できなくても全てのMIDIノートは反転できます。add13と6の同一構成音は6と表示します。

コード比較は「コード」と指定されたトラックの、その時点で持続しているノートを合わせて表示します（先頭8発音箇所）。サステインCCによる実際の残響・保持は解析には含めません。ピアノロールは先頭32拍までのプレビュー、最大各12,000ノート。変換・書き出しには全ノートを使います。

## 現在の制限

- 1ファイル20 MB、50,000ノート以下。Format 2、SMPTE時間形式、RIFF/RMID、MIDI 2.0、MPEの音程表現には未対応。
- オーディオ録音からの採譜、リアルタイムMIDI入力、AU MIDI FXプラグイン、DAWへの直接接続、自動キー推定、プロジェクト設定保存は未実装。
- Pitch BendやチューニングSysExは保持しますが反転しないため、ベンドを含む実際の音程は厳密なネガティヴハーモニーにならない場合があります。
- 調号メタ情報は元のままです。変換後の譜面の調号はDAWで調整してください。
- 比較再生は順次再生。再生位置のシーク・ループ・同位置での瞬時A/B切替は未実装。
- ピッチ名はフラット系表記で統一。キー別の異名同音表記には未対応。
- ドラッグ書き出しは実際の一時MIDIファイルを使用します。アプリの設定を変えてからドラッグしてください。一時ファイルはmacOSの一時領域に置き、古いドラッグ先が参照できるよう実行中は削除しません。
- UIの拡大縮小・スクロール可能な全曲ピアノロール編集は未実装。ノートを直接編集するDAWではありません。

## ビルド

XcodeまたはCommand Line Toolsを用意し、プロジェクトのフォルダで次を実行します。外部パッケージの取得は不要です。

```bash
./build.sh
./test.sh
```

生成先：`build/Negative Harmony MIDI Converter.app`

`build.sh`はSwiftコンパイル、コードで描画したアイコンのPNG/ICNS生成、Info.plist組み込み、ad-hoc署名まで行います。ビルドしたMacと同じCPU向けになります。Intel用を明示する場合：`ARCH=x86_64 ./build.sh`（Intel向けSDKサポートが必要）。

`Package.swift`をXcodeで開いてソースを確認・編集することもできます。`swift build -c release`で実行ファイルを作成できますが、`.app`とアイコンの生成は`build.sh`を使用してください。

## ソース構成

- `MIDI.swift`：境界チェック付きSMF読込・書出、Note On/Off対応付け、デモ生成
- `Harmony.swift`：pitch-class反転、コード解析、音域・Voice Leading・Blend
- `AppModel.swift`：非同期変換、AVMIDIPlayer、ファイル入出力、ドラッグ受け入れ
- `App.swift`：SwiftUI画面、ピアノロール、比較コード表示
- `Resources/DrawIcon.swift`：オリジナルのアプリアイコン描画
- `Tests/main.swift`：変換とMIDIイベント保持の自動検証
- `Examples/`：デモMIDIと変換結果

検証結果の詳細は `VALIDATION.md` を参照してください。
